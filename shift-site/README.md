# SHIFT — сайт магазину (Київ)

Односторінковий сайт: `index.html` (без збірки, просто відкрити в браузері або залити на будь-який хостинг — GitHub Pages, Netlify тощо).

## Що змінити під себе
- **Товари** — масив `PRODUCTS` у `<script>` (назва, бренд, ціна, стара ціна, категорія, бейдж, кольори картки).
- **Адреса, графік, телефон** — блок `#contacts`.
- **Соцмережі** — посилання `Instagram / TikTok / Telegram` (зараз `#`).
- **Карта** — `src` у `<iframe>` (координати `marker=`).
- **Кольори** — змінні `--accent`, `--accent2` у `:root`.
